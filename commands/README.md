# Commands

Custom command untuk menjalankan workflow berulang dari coding agent.

| Command | Kegunaan | File |
|---|---|---|
| `/commit` | Stage dan commit dengan Conventional Commits | [commit.md](./commit.md) |
| `/commit-push` | Stage, commit, dan push ke remote | [commit-push.md](./commit-push.md) |
| `/code-reviewer` | Review perubahan kode menggunakan skill reviewer | [code-reviewer.md](./code-reviewer.md) |
| `/transkrip-youtube` | Mengambil transkrip dan merangkum video YouTube | [transkrip-youtube.md](./transkrip-youtube.md) |

Gunakan `$ARGUMENTS` untuk meneruskan input tambahan ke command.
